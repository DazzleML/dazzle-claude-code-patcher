# Human Test Checklist: the history patch applies on Claude Code 2.1.330 again

**Target version:** 0.2.12
**Ships with commit:** v0.2.12 (TBD)
**Companion automated tests:** 223 in the suite. New: `tests/test_history_loader_switch.py::test_the_loader_switch_is_turned_on_and_the_tail_load_test_is_left_alone`, over the loader as written through 2.1.318, on 2.1.329 and on 2.1.330; the 2.1.330 case was red before the fix. `dcc-patcher check` on all 39 saved originals, 2.1.278 to 2.1.330: every edit of every patch applies.

## What this is

The history patch's first edit turns on the switch that makes the session loader parse the lines before the last compaction. 2.1.330 reads that switch as a property of a settings object where earlier builds called a function on the process environment, so the edit found nothing and the launcher printed `patch H needs attention; running stock`. The edit now takes whatever is assigned from the switch. Nothing the patch does changed. This is the edit the whole patch depends on, so the live check that matters is the resume: the automated check proves the edit lands, not that 2.1.330 still honours the switch the same way.

## Planning lineage

**Public (in this repo):** `CHANGELOG.md` [0.2.12]; the comment above the first edit in `dcc_patcher/patches/H-history-past-compaction/patch.toml`; `tests/one-offs/thinking/probe_find_text.py` (run for the switch's name on 2.1.329 and 2.1.330).

## Prerequisites

1. Claude Code 2.1.330 installed; the v0.2.12 checkout (the launcher imports it).
2. A session with at least two compactions in this project folder.
