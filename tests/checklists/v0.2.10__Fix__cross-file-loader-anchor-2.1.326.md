# Human Test Checklist: the cross-file history patch applies on Claude Code 2.1.326 again

**Target version:** 0.2.10
**Ships with commit:** v0.2.10 (TBD)
**Companion automated tests:** `tests/test_cross_file.py::test_the_loader_edit_keeps_the_head_as_written_and_appends_the_sibling_call` gains the 2.1.326 loader head; that case was red on the old pattern and is green on the new one, and the two earlier heads pass on both. `dcc-patcher check` on all 35 saved originals, 2.1.278 to 2.1.326: every edit of every patch applies; the cross-file edit lands once on each.

## What this is

The cross-file history patch's one edit anchors on the head of Claude Code's session-file loader, and carries the entry map maker's extra arguments as written. 2.1.326 gave the maker a third argument that holds a parenthesised group. The pattern allowed no parentheses there, so it found no site; the launcher printed `patch J needs attention; running stock` and ran stock Claude Code. The pattern now takes one level of parentheses in those arguments. Nothing the patch does changed. The automated check proves the edit lands on every saved build; only a real start proves the patched 2.1.326 runs.
