## What this is

2.1.314 changed one call inside Claude Code's chain walker: the five-second fallback now takes a per-walk cache as its first argument. Patch H's walker edit anchored on the exact call and stopped matching, so the launcher printed `dcc: Claude Code updated; building the patched copy... patch H needs attention; running stock` and ran stock Claude Code. The edit now captures the call's argument list whole and reproduces it as written. The automated check proves the edit lands on every saved build; only a real resume proves the patched 2.1.314 walks history as before, and only the maintainer runs a patched build.
