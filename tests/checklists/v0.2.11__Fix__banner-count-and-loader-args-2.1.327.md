## What this is

2.1.327 changed two things patches lean on. The classic session header, written twice until now, is written once; the banner patch required two copies and refused one. The call that builds the loader's entry map gained a fourth argument, nested two calls deep; the cross-file patch's edit described what those arguments could look like and stopped matching, for the second release running. The launcher printed `patch B, J needs attention; running stock`. The banner edit now accepts one copy or two. The loader edit now carries the arguments without describing them. A patch spec can list accepted counts (`expect = [1, 2]`). The automated check proves the edits land; only a real start proves the patched 2.1.327 runs and draws the header.

## High-Value Verification (~4 minutes)

- [ ] `claude --version`: one `dcc: ... building the patched copy... done; now running claude-dcc-2.1.327+dcc0.2.11.exe` line (before the commit the name may read `+dcc0.2.10`), then `2.1.327 + dcc 0.2.11 (Dazzle Claude Code)`. A further run prints only the version line.

Expected before the fix: `patch B, J needs attention; running stock` and a stock banner.

### HV.2 -- the classic header carries the label, wide and narrow

- [ ] `claude` in a normal-width terminal (not `/tui fullscreen`): the header reads `Dazzle Claude Code v2.1.327 · dcc 0.2.11`, the title bold and the versions dim.
- [ ] Narrow the terminal until the header no longer fits, and start `claude` again: the label is cut off at the edge, not wrapped onto a second line and not garbled. (This is the form 2.1.327 merged; the label is longer than stock's.)

### HV.3 -- a resume walks past its compactions

- [ ] Resume a session with compactions; `Ctrl+Home`: the first row is the session's first prompt, not `Compact summary`.

### HV.4 -- `check` on the originals

- [ ] `dcc-patcher check` on `claude-cc-2.1.326.exe` and `claude-cc-2.1.327.exe` in the builds folder: the banner patch reports `APPLIES x2` on the first and `APPLIES x1` on the second; the cross-file patch reports `APPLIES x1` on both. (Run on 2026-11-18 against all 36 originals: green.)
