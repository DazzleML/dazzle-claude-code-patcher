# Human Test Checklist: the flicker-free banner patch applies on Claude Code 2.1.323 again

**Target version:** 0.2.9
**Ships with commit:** v0.2.9 (TBD)
**Companion automated tests:** `tests/test_banner_flicker_free.py::test_the_flicker_free_banner_is_found_in_the_header_module_alone`, parametrized over the module layout through 2.1.322 and the 2.1.323 layout; the 2.1.323 case was red on the old marker and is green on the new one. `dcc-patcher check` on all 33 saved originals, 2.1.278 to 2.1.323: every edit of every patch applies.

## What this is

The flicker-free banner patch finds its module by a status message printed beside the fullscreen header. The fullscreen tips print the same words after a leading space. 2.1.323 split the two into separate modules, so the marker named two modules and the patch refused to choose; the launcher printed `patch B2 needs attention; running stock` and ran stock Claude Code. The marker now starts at the message's opening quote. Neither edit changed. The automated check proves the patch lands on every saved build; only a real start proves the patched 2.1.323 runs and draws the header.
