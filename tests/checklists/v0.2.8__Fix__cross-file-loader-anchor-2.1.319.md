# Human Test Checklist: the cross-file history patch applies on Claude Code 2.1.319 again

**Target version:** 0.2.8
**Ships with commit:** v0.2.8 (TBD)
**Companion automated tests:** 208 in the suite. New: `tests/test_cross_file.py::test_the_loader_edit_keeps_the_head_as_written_and_appends_the_sibling_call`, parametrized over the loader head through 2.1.318 and the 2.1.319 head; the 2.1.319 case was red on the old anchor and is green on the new one (an anchor, not a guard). `dcc-patcher check` on all 30 saved originals, 2.1.278 to 2.1.319: every edit of every patch applies; patch J's one edit lands once on each.

## What this is

2.1.319 reshaped the head of Claude Code's session-file loader: a local is declared before the entry map's maker, the maker takes a second argument, and a resume-head block sits between the destructure and `precede()`. Patch J's one edit anchored on the exact earlier head and stopped matching, so the launcher printed `dcc: Claude Code updated; building the patched copy... patch J needs attention; running stock` and ran stock Claude Code. The edit now carries those three pieces verbatim (empty on earlier builds). The automated check proves the edit lands on every saved build; only a real start proves the patched 2.1.319 runs, and only the maintainer runs a patched build.
